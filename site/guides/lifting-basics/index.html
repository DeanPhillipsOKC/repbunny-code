The basics, out loud

  1. What a rep and a set are, and what 3 × 8 means.
  2. How to pick a weight, and how long to rest.
  3. What RPE is, plus a few gym words: warm-up set, PR, and progressive overload.
  4. Logging your first set in RepBunny.

  1. Reps and sets

    3 × 8 means 3 sets of 8 reps. A rep is one lift, like one squat. A set is a group of reps done back to back. Rest between sets, then go again.

    In RepBunny, each set you log is one row: the weight and how many reps you did.

  2. Picking a weight

    Start light enough that the last rep or two feel hard while your form holds. When all your sets start to feel easier, add a little weight next time.

    When unsure, go lighter. You can always add weight on the next set.

  3. Rest

    Rest about 1 to 3 minutes between sets. Heavy lifts that use lots of muscle, like squats and deadlifts, need the longer end. In RepBunny, the rest timer starts when you add a set.

  4. RPE

    RPE is how hard a set felt, from 1 to 10. A 10 means you couldn't do another rep, and a set where you could have done about 2 more reps is RPE 8.

    Logging RPE is optional. With Premium, next-set targets use it to pick your next weight.

  5. Logging a set

    During a workout, type the weight and reps for the set you just did, then tap Add set. The Log a workout guide walks through a whole session.

    Not sure what to do? A starter program has the routines picked for you.
