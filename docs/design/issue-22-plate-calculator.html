#22 Plate calculator (Claude's default picks, 2026-09-29)

A mock of the suggested defaults, to decide whether this feature is worth building at all. Nothing here is approved yet.

What it is: a barbell weighs 45 lb on its own, and you load the same plates on each end. So to lift 185 lb you need 140 lb of plates, 70 lb per side, which is a 45 and a 25. Doing that subtraction and halving between sets is the annoying part. The calculator does it: you type the weight you want and it shows which plates to slide on each side.

1. Where you open it

Logging a barbell exercise shows a Plates button on the "Weight in lb / kg" line (highlighted). The set row itself has no room left for another button. Dumbbell, machine, and cable exercises never show it.

2. What it shows

A sheet opens with the weight you already typed (185). It draws the bar with the plates on it and lists one side in words. Change the number with − / + and the drawing updates. "Use 185 lb" drops the number back into the set row.

3. When the weight can't be made exactly

Plates only go up in steps (the smallest pair adds 5 lb), so something like 187 is impossible. Instead of guessing, the sheet offers the closest weight below and above. Tap one to pick it.

4. Settings (set once, then forget)

Top: in an exercise's edit screen, a "Uses a barbell" switch turns the Plates button on, plus which bar. It's pre-switched for library barbell lifts. Bottom: in the Account sheet, which plates your gym has. Assumes you have enough of each (no counting).
