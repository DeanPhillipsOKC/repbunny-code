#208 Import from Strong and Hevy

A new Import from another app row in Account > Your data, under Restore. You pick the app, then its CSV. The file is read on the phone and never sent anywhere. Every exercise name in the file gets one review row before anything is written; candidates come from your exercises first, then the library. Answers are remembered per app and name, so a newer export from the same app skips straight to the confirm screen.

Pick A or B for the review screen (screens 3a/3b); the rest is the same either way. Open questions settled here: history only (the files have routine names, not routine definitions; the workout's name goes in its note, "From Strong: Push Day"), RPE kept, warm-up sets skipped by default with a switch to keep them, so they don't count as records.

4 · Ready to import

Once every row is answered. Nothing is deleted, so no typed word. Already in RepBunny is decided by the sets, not the date: a workout from the file is skipped only when you already have a workout on the same day holding the same sets (same exercise, reps, weight and unit, or time and distance for timed sets), whether it came from an earlier import or you typed it in. Anything else on that day, like a different workout you backfilled, still imports. Workouts keep the unit they were logged in.
