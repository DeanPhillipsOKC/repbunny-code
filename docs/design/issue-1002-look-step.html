Closer to today, but uneven. The two main looks keep their big rows, and the More themes become slim swatch rows to stay short. Those rows don't show the art, so they aren't "the same tiles" you asked for.

Recommended: Option A. It's what you described: one switch, then every theme drawn the same way, two per row, so the open accordion stays about one screen tall. Option B keeps today's big rows but has to shrink the extra themes into swatches to fit.

Premium themes in setup (owner, 2026-11-05): nobody buys before their first workout, but people should know the other themes exist. So setup shows every theme with no per-tile Premium tag and no price. Leaving setup with a Premium theme picked starts a one-time 7-day Themes trial; when it ends, the app goes back to Classic and shows the trial-end note once (state 4). A setup replay doesn't start a second one. This loosens the 2026-10-31 rule ("no Premium label, no third theme tile in setup"), so docs/decisions.md gets updated with the change.
