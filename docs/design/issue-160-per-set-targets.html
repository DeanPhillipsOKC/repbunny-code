#160 Per-set targets that adjust after each logged set (2026-10-05)

Barbell Bench Press with Premium. Last time: 180 × 12 at RPE 8, 180 × 11 at RPE 9, 180 × 10 at RPE 9.5. Each set gets its own target from the same set last time. Once you log a set, the sets after it follow it: RPE 9.5+ holds the weight with 1 fewer rep, RPE 7 or less goes up a step, anything else repeats it. Rows still start from last time, and nothing fills until you tap.

The width is the hard part: a 375px row already uses all 307px (Set 28 + Weight ~69 + Reps 54 + RPE 44 + buttons 88), so a per-row target can't sit inside the row. It goes on its own line (B), or stays in the one card above the rows (A).

Option A: one card that follows you

Before any set

The #140 card stays put and names the set it fills: Set 1 target. The row it fills gets a pink outline. A small line under it previews the sets after.
