#181 Session list on a lift's progress screen

Today every session under the chart is a date heading over plain text lines ("8 × 225 lb · RPE 8"), and all of them render at once. Each option below makes it one card per session (date, template name when there is one) with the sets in aligned columns, a gold paw on a set that was a record when it was logged (same paw as the Workout log's "PR set this workout"), and the newest 10 sessions, then Show older adds 10 more.

Columns follow the lift's load type: Weight / Reps / RPE for weights; Added / Reps for bodyweight; Assist / Reps for assisted; Level / Reps for level; Time plus whichever of Distance, Incline, Level, Cal the session logged for timed. RPE only shows when a session has one. Each set keeps the unit it was logged in, so a kg session stays kg.

Option A · Table with headings

Closest to "put it in tables." Small column headings in each card, numbers right-aligned so weights line up down the page. The record row turns gold with a paw.
