First-run setup wizard

Replaces the one-screen splash (OnboardingScreen.vue, which today only shows in the PWA before sign-in and never shows in the native app, since local mode is always "signed in"), the one-off WeightUnitSheet, and the Home welcome card from #207. Four steps, each skippable, about 30 seconds. Fresh installs only; existing users never see it, and anyone can run it again from Preferences.

The look step is the point of the redesign: the second thing a new user sees is that RepBunny can be steel blue with no bunny art. Classic, Chalk, and the Minimal mascot are all free. Tapping a look repaints the wizard right away, so steps 3 and 4 below are shown in Chalk.

1 · Welcome

Short and warm, then straight to setup. The three promises answer "why this app" before asking for anything. Skip setup uses the defaults (lb, Classic) and lands on Home with the welcome card.
