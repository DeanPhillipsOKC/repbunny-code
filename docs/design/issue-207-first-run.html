#207 First-run onboarding

A brand-new account (no exercises, no templates) lands on Home. Today it says "Add your first exercise" and sends you to the Exercises tab. Instead, the welcome card offers three ways in, and the workout tiles show even with zero exercises. Pick A or B for the welcome card; the other screens are the same either way.

Uses the current word template; #206 renames it to routine when it ships. Gold numbers mark the taps from Home to a logged set: Start a workout, + Add, Log set. To fit 3 taps, the first pick in a workout with no exercises yet closes the sheet and opens that exercise; after that the sheet works as now (pick several, then Done).

A · Welcome, stacked buttons

Same card and mascot as today. Start a workout is the pink primary, Build a template the lavender outline. A divider then the program row, dashed like the Starter programs rows, so it reads as a real third choice.
